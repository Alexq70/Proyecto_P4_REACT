## 📝 Descripción

Proyecto P4 REACT es una aplicación full-stack que combina un frontend moderno con React y un backend robusto. El proyecto está diseñado para demostrar buenas prácticas en el desarrollo web contemporáneo, incluyendo separación de responsabilidades, componentes reutilizables y comunicación eficiente cliente-servidor.

## 🛠️ Tecnologías

### Frontend
- **React** - Librería de interfaz de usuario
- **Vite** - Herramienta de construcción y desarrollo rápida
- **CSS** - Estilos personalizados
- **Node.js** - Entorno de ejecución

### Backend
- **Node.js** - Entorno de ejecución del servidor
- Tecnologías adicionales según configuración del backend

## 🚀 Instalación

### Requisitos previos
- Node.js (versión 14 o superior)
- npm o yarn

### Pasos de instalación

1. **Clonar el repositorio**
```bash
git clone https://github.com/Alexq70/Proyecto_P4_REACT.git
cd Proyecto_P4_REACT
```

2. **Instalar dependencias del frontend**
```bash
cd frontend
npm install
```

3. **Instalar dependencias del backend** (si aplica)
```bash
cd ../Backend
npm install
```

## ▶️ Ejecución

### Ejecutar el frontend

```bash
cd frontend
npm run dev
```

La aplicación estará disponible en `http://localhost:5173` (puerto por defecto de Vite)

### Ejecutar el backend

```bash
cd Backend
npm run start
# o según la configuración específica de tu backend
```

### Ejecutar ambas partes simultáneamente

```bash
# Opción 1: En dos terminales diferentes
# Terminal 1
cd frontend
npm run dev

# Terminal 2
cd Backend
npm run start

# Opción 2: Usar un gestor de procesos como concurrently (si está configurado)
npm run dev
```

## 🔨 Scripts disponibles

### Frontend
- `npm run dev` - Inicia el servidor de desarrollo
- `npm run build` - Construye la aplicación para producción
- `npm run preview` - Previsualiza la construcción de producción
